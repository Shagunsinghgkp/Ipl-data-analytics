# IPL Data Analysis

A data analysis project based on IPL match data to explore team performance, player performance, and match statistics.

## Features
- Analyze IPL match data
- Explore team performance
- Analyze player performance
- Study batting and bowling statistics
- Visualize important insights using charts
- Identify patterns and trends in match data

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Dataset
The project uses IPL match data containing information such as teams, players, innings, overs, balls, and match-related statistics.

## Purpose
This project was created to practice data cleaning, data analysis, and data visualization using Python.
